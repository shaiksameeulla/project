To retrieve the names of managers who have 5 or more employees reporting to them, you can use a SQL query. Assuming you have a table named employees with columns emp_id, emp_name, and manager_id, you can use the following query:

 

sql

Copy code

SELECT e1.emp_name AS manager_name

FROM employees e1

INNER JOIN (

    SELECT manager_id, COUNT(*) AS emp_count

    FROM employees

    GROUP BY manager_id

    HAVING COUNT(*) >= 5

) e2 ON e1.emp_id = e2.manager_id;

This query first calculates the count of employees for each manager using a subquery and then selects only those managers who have 5 or more employees reporting to them. It retrieves the manager's name based on the manager_id from the employees table.

Q. To find the managers who have 5 or more employees reporting using Java 8, you can follow these steps:

 

Group the employees by their manager IDs.

Filter the groups to include only those with 5 or more employees.

Map the manager IDs to their corresponding manager names.

Collect the manager names into a list.

Here's how you can implement this in Java 8:

 

java

Copy code

import java.util.*;

import java.util.stream.Collectors;

 

public class Main {

    public static void main(String[] args) {

        List<Employee> employees = Arrays.asList(

            new Employee(1, "John", 101),

            new Employee(2, "Alice", 101),

            new Employee(3, "Bob", 102),

            new Employee(4, "Carol", 102),

            new Employee(5, "David", 102),

            new Employee(6, "Emma", 103),

            new Employee(7, "Frank", 103),

            new Employee(8, "Grace", 103),

            new Employee(9, "Henry", 103),

            new Employee(10, "Ivy", 103),

            new Employee(11, "Jack", 104),

            new Employee(12, "Kate", 104)

        );

 

        Map<Integer, Long> managerEmployeeCount = employees.stream()

                .collect(Collectors.groupingBy(Employee::getManagerId, Collectors.counting()));

 

        List<String> managersWithFiveOrMoreEmployees = managerEmployeeCount.entrySet().stream()

                .filter(entry -> entry.getValue() >= 5)

                .map(entry -> getManagerName(entry.getKey(), employees))

                .collect(Collectors.toList());

 

        System.out.println("Managers with 5 or more employees reporting: " + managersWithFiveOrMoreEmployees);

    }

 

    public static String getManagerName(int managerId, List<Employee> employees) {

        Optional<Employee> manager = employees.stream()

                .filter(e -> e.getEmpId() == managerId)

                .findFirst();

        return manager.isPresent() ? manager.get().getEmpName() : "Unknown";

    }

}

 

class Employee {

    private int empId;

    private String empName;

    private int managerId;

 

    public Employee(int empId, String empName, int managerId) {

        this.empId = empId;

        this.empName = empName;

        this.managerId = managerId;

    }

 

    public int getEmpId() {

        return empId;

    }

 

    public String getEmpName() {

        return empName;

    }

 

    public int getManagerId() {

        return managerId;

    }

}

This program will output the names of managers who have 5 or more employees reporting. Adjust the Employee class and the sample data according to your actual data structure.
